# 🎨 Odysseus Custom Themes

A curated collection of beautiful, high-quality color palettes and themes for **[Odysseus](https://pewdiepie-archdaemon.github.io/odysseus/)**, the self-hosted AI workspace.

## 🌌 The Catppuccin Collection
This repository includes a full port of the official Catppuccin themes, designed to minimize eye strain during long chat sessions.

### 1. ☕ Catppuccin Mocha (Dark Mode Default)
Our signature dark theme mapped carefully to the Odysseus layout.
* **Background:** `#1e1e2e`
* **Panel:** `#181825`
* **Border:** `#313244`
* **Text:** `#cdd6f4`
* **Sidebar:** `#11111b`
* **Accent:** `#cba6f7` (Mauve)

### 🌊 Other Flavors Included
* **Catppuccin Macchiato (Medium Dark):** Uses `#24273a` as the base with `#f4dbd6` text for a warmer dark mode aesthetic.
* **Catppuccin Frappé (Muted Dark):** Uses `#303446` gray base for softer contrast.
* **Catppuccin Latte (Light Mode):** A crisp, soothing light mode utilizing `#eff1f5` and `#4c4f69`.

## 🛠️ How to Install a Theme

Odysseus allows you to configure your workspace colors directly through the settings interface or by inputting theme files.

### Option 1: Manual Setup via Settings Menu
1. Click the **Settings** icon inside your Odysseus application.
2. Navigate to the **Appearance** or **Theming** tab.
3. Copy the hexadecimal color values from your chosen flavor above.
4. Paste each hex value into its corresponding layout slot (Background, Panel, Border, Text, Sidebar, Accent).
5. Click **Save Changes**.

### Option 2: Importing the JSON Configuration File
1. Download or copy the raw text from any `.json` theme file in this repository.
2. Locate the Odysseus application configuration directory on your machine.
3. Paste the contents or import the JSON file directly into your user themes folder.
